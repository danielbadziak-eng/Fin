# FinançasPRO 4.7.2 — Psicologia do Zero

- Novo convite contextual para patrimônio sem cadastro.
- Substitui o zero frio por um primeiro passo acionável.
- Ação principal: adicionar patrimônio.
- Ação secundária: importar dados.
- Só aparece quando não existem itens de patrimônio cadastrados; saldo zero real não é mascarado.
