# FinançasPRO 5.1.0 — GitHub Pages Beta

## Publicação gratuita
1. Crie uma conta no GitHub.
2. Crie um repositório público, por exemplo `financaspro`.
3. Envie TODOS os arquivos desta pasta para a raiz do repositório.
4. Vá em **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha `main` e `/ (root)` e salve.
7. Aguarde a publicação.
8. Abra no Android a URL exibida pelo GitHub Pages.

## Instalação no Android
Abra a página pelo Chrome. Quando o site atender aos critérios de instalação, use o menu do Chrome e escolha **Instalar app** ou **Adicionar à tela inicial**.

## Importante
Esta é uma versão beta local-first. Os dados financeiros ficam no armazenamento do navegador/aplicativo. Não coloque dados bancários reais enquanto não houver backend, autenticação e política de segurança definidos.
