# FinançasPRO 5.0 — App Foundation

## Objetivo
Transformar o protótipo 4.7.x em uma experiência de aplicativo instalável, mobile-first e preparada para evolução para SaaS, preservando o Financial Engine e o FIN atuais.

## Nesta entrega
- PWA manifest e Service Worker.
- Instalação pelo navegador quando servido em HTTPS/localhost.
- Navegação inferior para uso no celular.
- Ação rápida central de nova transação.
- Botão de instalação do app quando o navegador disponibilizar o prompt.
- Safe-area para aparelhos com gesto/notch.
- Base preservada em modo local-first; ainda não há autenticação/backend multiusuário.

## Próxima camada de produto
1. Backend/API e autenticação.
2. Banco de dados por usuário.
3. Sincronização segura entre dispositivos.
4. Billing/assinaturas.
5. FIN conectado a ações estruturadas do Financial Engine.
6. Onboarding comercial e métricas de ativação/retenção.

## Princípio
Registrar → Entender → Diagnosticar → Simular → Decidir.
