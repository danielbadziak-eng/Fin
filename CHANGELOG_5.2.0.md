# FinançasPRO 5.2.0

- Navegação principal reduzida para Visão geral, Movimentações, Patrimônio, FIN e Mais.
- No Android, as sete abas superiores deixam de aparecer; o acesso secundário fica em Mais.
- Salvamento de transações ficou resiliente a avisos de integridade do legado.
- Falhas de renderização do Dashboard não são apresentadas como se fossem falhas de salvamento.
- Lançamentos de fatura exigem cartão previamente cadastrado.
- Sem cartão, o usuário recebe um fluxo direto para cadastrar o cartão e retornar à transação.
- Cache PWA atualizado para 5.2.0.
